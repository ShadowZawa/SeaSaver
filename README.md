# SeaSaver｜海洋打撈隊

把遊戲裡的善意帶上岸。結合限時吊鉤遊戲、海廢圖鑑、情境問答與個人化海洋行動的互動網頁前端。

## 功能

- 三個海域的打撈挑戰：晴空海灣、珊瑚海岸、深藍航道。
- 五種海廢及不同分數、重量；玩家須避開魚群。
- 首次發現介紹、可重讀的海廢圖鑑，以及報導來源與閱讀脈絡。
- 關卡情境問答、友善回饋、背景音樂及音效控制。
- 依角色、生活情境、可投入時間及遊戲統計請求個人化行動建議。
- 行動完成紀錄儲存在目前瀏覽器的 localStorage。

## 本機執行

本專案不需要安裝套件或建置。使用靜態 HTTP 伺服器提供此資料夾，例如：

```sh
python -m http.server 8080
```

開啟 `http://localhost:8080`，按「開始打撈」即可遊玩。可使用空白鍵、點擊海面或「放出吊鉤」按鈕操作。

## AI 後端

此儲存庫只包含前端。個人化行動功能目前向下列獨立服務發送 POST 請求：

```text
https://twswapi.cloudns.nz:3005/api/personal-action
```

部署到新網址時，後端須允許該網站來源的 CORS 請求，並維持有效 HTTPS 憑證。若更換服務網址，請同步修改 `ocean-cleanup.js` 中的請求網址與連線錯誤提示。

請求包含角色、情境、可投入時間、選填補充內容及遊戲統計。請勿填寫姓名、電話等個人資料。OpenAI API 金鑰應僅保存在後端，不可加入此前端儲存庫。

## 驗證

使用 Node.js 執行內建測試：

```sh
node --test tests/game-flow.test.cjs
```

測試涵蓋首次發現、圖鑑暫停、情境問答、重試、過關及畫面尺寸調整等遊戲流程。

## 專案檔案

```text
index.html                  頁面與對話介面
ocean-cleanup.css           視覺樣式與響應式版面
ocean-cleanup.js            Canvas 遊戲、圖鑑、問答與 AI 前端串接
tests/game-flow.test.cjs    遊戲狀態流程測試
```

作品中的分數、打撈數量與生態恢復視覺皆為遊戲模擬，不代表真實海洋清理成果。圖鑑及問答使用固定內容；AI 用於個人化行動建議，Codex 協助程式開發與整合。
